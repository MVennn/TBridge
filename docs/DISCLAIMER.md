# 免责声明（全文）

> **一句话**：使用本模块前请读完这一页——它说明桥做什么、不做什么，以及本地调试通道的访问控制由谁负责。

## 1. 项目性质

TBridge（下称「本项目」）是个人开发的开源 LSPosed 模块，用途是**在受控设备上做 UI 自动化测试**：在被测 App 进程内开一个 abstract unix socket，把控件树、节点查找、点击、设文本、View 层截图以一行 JSON 暴露给 PC 端脚本。本项目**非官方**，与任何被测 App 的开发者均无隶属、合作、授权、认可或支持关系。

## 2. 仅供学习与受控测试

本项目仅供学习 Android Hook / View 技术，以及在自己拥有或已获准测试的设备与 App 上使用。请在受控开发环境内使用，别把它接到不受信网络或公开可达的端口上。

## 3. 不采集任何数据

本项目不收集、不上传、不存储任何个人信息；模块内没有网络通信、统计、广告或数据回传组件；`AndroidManifest.xml` 未声明任何 `uses-permission`。控件树与 View 层截图只在请求 / 响应里即时返回，不落盘、不缓存。

## 4. 不修改宿主安装包

本项目不修改任何 App 的安装包、不绕过鉴权、不读写账号数据、不自动执行任何操作。所有动作都由 PC 端显式发起的一行 JSON 请求触发。

## 5. 本地调试通道的访问控制

桥经 `adb forward tcp:27110 localabstract:tb.<包名>` 暴露，是**本地调试通道**，不带认证、不加密。访问控制由使用者自行负责：只在自己可控的设备与主机上使用，别把端口转发到不受信网络，用完及时关闭 forward。
